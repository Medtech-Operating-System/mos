# Document Register — {{company}}

Every document MOS writes for this company, with its number, its current file, revision and
status. MOS keeps it up to date: a new draft gets the next number for its domain when it is
written, keeps that number through every revision, and each clean copy records its revision
here. Edit it by hand to set a status or enter a number; MOS keeps what you write.

Numbering: {{MOS, or Quality system where the company's own system assigns document numbers}}

**Numbering** — with `MOS`, a new document gets the next number for its domain's prefix:
`DIR-001`, then `DIR-002`. With `Quality system`, MOS assigns none; enter the number your system
gives each document in the table below, and MOS puts it on every later revision.

**Status** — `Draft`; `Draft of rev B` while a revision is being drafted; `Clean copy, for
signature` once its clean copy is made; `In quality system` once it is signed and filed there,
which you set; `Retired` for a document no longer used. A retired number is never reused.
